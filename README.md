<h2>📋 What is oncellclaw?</h2>
<p>oncellclaw is a personal AI assistant powered by Claude that lives permanently in the cloud. Think of it as your own intelligent helper that never sleeps, never crashes, and remembers everything you tell it. Unlike typical AI assistants that reset or lose context, oncellclaw keeps your conversations going across days, weeks, or months without missing a beat.</p>
<p>Built on OnCell technology, each oncellclaw instance runs in its own isolated "cell" — a secure, durable environment in the cloud. This means it costs almost nothing when you're not talking to it (pennies per month), wakes up instantly when you send a message, and can connect to popular messaging apps like Telegram and WhatsApp.</p>

<h2>🛠️ Technical Details (Optional Reading)</h2>
<p>oncellclaw is a fork of NanoClaw, re-engineered to run agents in cloud cells instead of local containers. Each agent is isolated using lightweight virtualization, ensuring crash isolation and persistent memory. The system uses a pay-per-use model for cloud resources, keeping costs minimal during idle periods. Supported integrations include Telegram Bot API and WhatsApp Business API.</p>
